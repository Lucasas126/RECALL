      Folders on the computer running RECALL, such as an Obsidian vault. Each one is a source named after it (name:path/note.md). Chats reach them with the folder tool groups; dreams only read them.
      
            
      Indexed folders feed associative memory and query_memory. A read-only folder is never edited, whatever the tool groups.

      Information
      
            Choosing a model for a chat sets only that chat's override.
        The default entry removes it (the agent's default model, else yours). Defaults in Settings are saved with Save settings.
        Favorites are shared across your agents.
            
      
            Prices are starting rates in USD per 1M tokens; provider,
        context tiers, caching and extras may change charges.
            
      
            Capability filters use catalog metadata, not a routing guarantee.
        Image input describes the model; the composer also accepts image, video
        and audio attachments when the selected model declares support.
        PDFs are converted to text on the server and work with any model.
        Filters do not enable tools or reasoning in the agent.
            
      
            OpenRouter's ZDR policy includes caching and legal exceptions;
        embeddings and external tools have separate policies.
